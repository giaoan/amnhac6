Hướng Dẫn Nhập Hàng Loạt

Vui lòng dán dữ liệu vào ô dưới đây theo định dạng **JSON Array**. Sử dụng **Tên Chủ đề** (ví dụ: `Dân ca Xoan`) chứ không phải ID của Chủ đề.

 [
    {
        "topicName": "Tên Chủ đề phải tồn tại",
        "type": "MC", // Hoặc "FITB"
        "text": "Đây là câu hỏi trắc nghiệm?",
        "options": ["Lựa chọn A", "Lựa chọn B", "Lựa chọn C", "Lựa chọn D"],
        "correctIndex": 0 // Chỉ mục (0, 1, 2, hoặc 3) của đáp án đúng trong options
    },
    {
        "topicName": "Tên Chủ đề khác",
        "type": "FITB",
        "text": "Điền vào chỗ trống: Việt Nam có bao nhiêu dân tộc?",
        "correctAnswerText": "54" // Đáp án chính xác cho câu điền trống
    }
]
